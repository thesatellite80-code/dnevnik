Ввод из опросника / сырых ответов

Пустые строки игнорируются. Всё кроме названия необязательно: срок по умолчанию — дедлайн текущего шага, часы — 0.5, тэг «входящие» добавится сам.

Напоминания

Работает при открытой странице. Чтобы напоминание пришло при закрытом браузере — поставьте задачу в Планировщике Windows (команда в файле ЗАПУСК-Windows.md).
